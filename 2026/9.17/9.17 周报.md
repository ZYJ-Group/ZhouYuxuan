### 2. 文献阅读整理

- **综述类：**
  - 点云场景分割综述，重点搞清楚了投影方法、三维方法、混合方法的区别，以及精度和效率之间怎么权衡

  - 图生文综述，了解了图像理解 + 文本生成的基本流程
- **具体论文：**
  - VGGT：用前馈式 Transformer 从多视角图像直接恢复相机参数、深度和点图
  - CamoDiffusion：条件扩散模型做伪装目标和显著目标检测，从噪声 mask 一步步去噪生成目标掩码，主要解决边界模糊和过度自信的问题
  - 条件扩散模型做轨迹预测：根据过去轨迹和场景信息生成未来的多模态轨迹（这篇当时最感兴趣）
  - 条件扩散模型做图像融合：多源图像信息融合的思路
  - 3DGS 原文：显式三维高斯原语、自适应密度控制、tile 光栅化 + α 混合，1080p 能跑到实时；重点记了它假设密集视角，而 GaussianObject 是往少视角扩的

#### 4.3 第三章：GaussianObject 少视角稠密重建

主要五个环节：

```
Visual Hull    →  用 mask 和相机信息做一个粗糙的三维外壳
Coarse 3DGS    →  把粗糙外壳训练成一个能渲染的初始高斯模型
Leave-One-Out  →  故意少用一个视角，造出"粗糙渲染图 - 真实图"的训练对
LoRA 微调      →  让修复模型学会把粗糙渲染图修得更像真实图
Gaussian Repair→  用修好的模型反过来修补三维高斯模型
```

- 官方的 kitchen 案例整套流程都跑通了，包括 Visual Hull、Coarse 3DGS、粗糙模型渲染、留一法、LoRA 微调和 Gaussian Repair。粗糙模型的渲染跟真实图还有明显差距，修复之后好很多。

#### 4.6 把整条链路串起来

跑过的代码大致可以串成这样一条链路：

```
图像序列
→ SuperGlue 关键点匹配
→ SVD 稀疏三维重建
→ GaussianObject 少视角稠密重建
→ 二维 mask 到三维点云的语义投票
→ TurboReg 点云配准
```

每个环节对应的方法和作用大概是：

| 环节           | 方法                     | 作用                 |
| -------------- | ------------------------ | -------------------- |
| 特征对应       | SuperGlue 图像关键点匹配 | 提供初始几何关系     |
| 位姿与初始几何 | SVD / DUSt3R             | 位姿估计 + 初始点云  |
| 稠密重建       | GaussianObject           | 少视角高质量重建     |
| 语义分割       | mask 投影投票            | 把二维标签提升到三维 |
| 配准拼接       | TurboReg                 | 部件点云配准与拼接   |

- 精读了两篇：
  - **ML-SemReg**：把误匹配分成跨类和类内两类分别处理，组匹配只看局部邻域的语义构成有没有交集，掩码匹配用多环语义签名比较场景上下文
  - **SC2-PCR**：提出了二阶空间相容性，不只看两条对应本身，还看它们共同相容的对应有多少，从概率上说明它比一阶相容性更抗离群点。这篇是师兄论文第四章 TurboReg 里相容图思想的源头，读完把"相容图 → 谱匹配/种子选择 → 两阶段采样 → 加权 SVD"这条链路和代码里的模块对上号了。
